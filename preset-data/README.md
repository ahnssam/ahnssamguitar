# preset-data — 코드 진행 프리셋 파일 모음

반주(코드 메이커) 페이지에서 **저장 ▸ 파일로 내보내기**로 내려받은 `.json` 파일을 여기에 모아둡니다.

## 흐름
1. 반주 페이지에서 코드 진행을 만든 뒤 **저장 드롭다운 ▸ 파일로 내보내기** → 곡명·아티스트 입력 → `아티스트 - 곡명.json` 다운로드.
2. 내려받은 파일을 이 폴더(`preset-data/`)에 모아둡니다.
3. 프리셋 빌더(`presets-builder.html`)에서 **파일 열기**로 그 파일을 열면 곡명·아티스트·BPM·코드·리듬·도돌이가 폼에 그대로 채워집니다.
4. 장르·난이도만 확인/지정하고 **저장**하면 기본 프리셋 목록에 추가됩니다.

## 파일 형식
- 확장자: `.json`
- 파일명: `아티스트 - 곡명.json` (아티스트가 없으면 `곡명.json`)
- 내용: `presets` 테이블과 호환되는 필드(name, artist, bpm, bars, rhythm, bass_style, piano_style, chords_a, chords_b, sequencer_pattern 등). `_format: "ahnssam-preset"` 표식 포함.

## 참고
- 빌더는 한 마디당 코드 2개(A/B)와 도돌이표까지 반영합니다. 4코드(마디당 4개)·볼타·송폼 같은 표시는 기본 프리셋에는 저장되지 않습니다.
