# 부릉부릉 출동! — 그림 GPT 프롬프트 (뒤에서 본 3D 레이싱 화면용)

놀이터의 아이용 놀이 `play/car.html`(안쌤 계정 전용)에 넣을 그림을 뽑는 프롬프트다.
2026-11-14에 화면을 **뒤에서 따라가는 3인칭 레이싱**으로 바꿨다. 그래서 탈것은 **옆모습이 아니라 뒷모습**이 필요하다.
지금은 Claude가 코드로 그린 그림이 나오고, 그림을 받으면 `images/play/car/<이름>.webp`로 넣은 뒤 `car.html`의 `ART`에 적으면 바뀐다.

필요한 그림은 두 가지다. **① 탈것 17대(뒷모습)**가 먼저고, **② 길가 풍경 8가지**는 있으면 더 예쁘다.

## 꼭 지킬 것 (모든 그림 공통)

- **투명 배경 PNG**, 정사각형 1024×1024, 한 장에 **하나만**, 가운데에 크게.
- 그림자·바닥·글자·숫자·로고 없음. 눈·입 같은 얼굴 없음(타요 같은 캐릭터와 닮지 않게).
- 30개월 아기가 보는 그림: 둥글둥글, 밝고 부드러운 파스텔 톤, 굵고 부드러운 외곽선, 단순한 면 채색.
- 전부 **같은 그림체**여야 한다. 첫 장이 마음에 들면 "같은 그림체로 다음"으로 이어서 뽑는다.

## ① 탈것 — 뒷모습 (레이싱 게임에서 내 차를 뒤에서 보는 모습)

### 그림체를 정하는 첫 장 (경찰차)

```
3인칭 레이싱 게임에서 내 차를 뒤에서 따라가며 보는 시점의 귀여운 경찰차 일러스트 한 대.
차의 뒷면이 정면으로 보이고(뒤 유리, 빨간 꼬리등 두 개, 뒤 범퍼, 뒷바퀴 두 개), 카메라는 차 바로 뒤에서 살짝 위에 있어 지붕이 조금 보인다.
좌우 대칭, 차가 화면 위쪽(앞)으로 달려가는 방향.
아기 그림책 스타일: 둥글둥글한 모양, 밝은 파스텔 톤, 굵고 부드러운 진한 남색 외곽선, 단순한 면 채색에 은은한 하이라이트.
흰색 차체에 파란 띠, 지붕 위에 빨강·파랑 경광등.
얼굴(눈·입) 없음, 글자·숫자·번호판 글씨·로고 없음, 그림자·바닥 없음.
투명 배경 PNG, 정사각형 1024×1024, 차가 가운데에 크게.
```

### 같은 그림체로 한 대씩

아래 문장을 앞에 붙이고, 표의 설명을 하나씩 넣는다.

```
방금 그림과 똑같은 그림체·외곽선·색감·크기·시점(뒤에서 살짝 위에서 본 뒷모습, 좌우 대칭)으로, 투명 배경 PNG 1024×1024, 얼굴·글자·그림자 없이 한 대만:
```

| 파일 이름 | 붙일 설명 |
|---|---|
| `police` | (첫 장) 경찰차 |
| `fire` | 빨간 소방차의 뒷모습. 지붕 위에 은색 사다리가 앞쪽으로 누워 있고, 뒷문 양쪽에 노란 띠, 지붕에 빨간 경광등 |
| `amb` | 흰색 구급차의 뒷모습. 네모난 뒷문에 빨간 십자, 지붕에 빨강·파랑 경광등 |
| `tow` | 노란 견인차(레커차)의 뒷모습. 뒤쪽에 갈고리 달린 크레인 팔이 솟아 있음 |
| `car` | 빨간 작은 자동차(둥근 소형차)의 뒷모습 |
| `bus` | 노란 버스의 뒷모습. 키가 크고 네모나며 큰 뒤 유리, 흰 띠 |
| `taxi` | 주황색 택시의 뒷모습. 지붕에 노란 표시등 |
| `truck` | 파란 화물 트럭의 뒷모습. 네모난 짐칸의 양쪽 여닫이 뒷문 |
| `excavator` | 노란 굴착기(포클레인)의 뒷모습. 무한궤도 바퀴, 운전실, 위로 솟은 긴 팔과 바가지 |
| `dump` | 주황색 덤프트럭의 뒷모습. 큰 짐칸 뒷판에 가로 홈 |
| `mixer` | 하늘색 레미콘의 뒷모습. 뒤에 줄무늬가 감긴 큰 둥근 통 |
| `tractor` | 초록 트랙터의 뒷모습. 아주 큰 뒷바퀴 두 개와 작은 운전실, 굴뚝 |
| `garbage` | 초록 청소차(쓰레기 수거차)의 뒷모습. 뒤쪽에 큰 수거함 입구 |
| `train` | 빨간 증기 기관차의 뒷모습. 네모난 뒤칸에 창문 두 개, 앞쪽 굴뚝에서 하얀 연기 |
| `heli` | 노란 헬리콥터의 뒷모습. 위에 큰 프로펠러, 뒤로 뻗은 꼬리, 아래 착륙 다리 |
| `plane` | 하늘색 여객 비행기의 뒷모습. 양옆으로 넓게 뻗은 날개, 날개 아래 엔진 두 개, 위로 선 꼬리날개 |
| `rocket` | 빨강·흰색 로켓. **위로 솟아오르는 모습**(뾰족한 머리가 위, 아래에 날개 세 개와 주황 불꽃, 가운데 둥근 창) |

- 한 장에 여러 대를 격자(예: 3×2)로 뽑아도 된다. 그때는 "배경은 완전한 흰색 한 가지, 탈것끼리 겹치지 않게 넉넉히 띄워서"를 덧붙이면 Claude가 잘라 넣는다.
- 뒷모습이 어렵게 나오면(옆으로 돌아간 그림) "차의 뒷면이 정면으로, 좌우 대칭"을 다시 강조한다.

## ② 길가 풍경 — 앞에서 본 모습 (길 옆에 세우는 그림)

길 양쪽에 세워져서 멀리서 다가오는 그림이다. 똑바로 서 있는 **정면 모습**, 아래가 땅에 닿는 모양으로.

```
방금 탈것 그림과 같은 아기 그림책 그림체(둥글둥글, 파스텔, 굵은 외곽선)로, 정면에서 본 모습, 아래쪽이 땅에 닿게 똑바로 서 있는 그림 하나.
투명 배경 PNG 1024×1024, 글자·그림자·바닥 없음:
```

| 파일 이름 | 붙일 설명 |
|---|---|
| `tree` | 동그란 초록 나무 한 그루 |
| `pine` | 세모난 소나무 한 그루 |
| `house` | 빨간 세모 지붕의 작은 집(문 하나, 창문 둘, 굴뚝) |
| `tower` | 창문이 많은 파스텔 색 높은 건물 |
| `sign` | 기둥 위에 동그란 표지판(안에 흰 별 하나, 글자 없음) |
| `light` | 신호등(빨강·노랑·초록 세 칸) |
| `balloon` | 줄에 묶인 풍선 세 개 |
| `flower` | 큰 꽃 세 송이 |

- 더 넣고 싶은 것(주유소, 풍차, 터널 입구, 다리, 강아지 등)이 있으면 같은 식으로 뽑아서 알려 주면 길가에 더한다.

## 받은 뒤 (Claude가 하는 일)

1. 하나씩 잘라 투명 가장자리를 다듬고 긴 쪽 640px webp로 `images/play/car/<파일 이름>.webp`에 넣는다.
2. `play/car.html`의 `ART`에 `{ police: 1, fire: 1, tree: 1, … }`처럼 적는다(그림을 바꾸면 숫자를 올린다).
3. 로컬에서 탈것이 길 위에 바로 서는지, 길가 그림이 땅에 닿는지 확인한다.
