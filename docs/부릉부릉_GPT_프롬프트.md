# 부릉부릉 출동! — 그림 GPT 프롬프트 (뒤에서 본 3D 레이싱 화면용)

놀이터의 아이용 놀이 `play/car.html`(안쌤 계정 전용)에 넣을 그림을 뽑는 프롬프트다.
화면이 **뒤에서 따라가는 3인칭 레이싱**이라 탈것은 **옆모습이 아니라 뒷모습**이 필요하다.
지금은 Claude가 코드로 그린 17대가 나오고, 그림을 받으면 `images/play/car/<이름>.webp`로 넣은 뒤 `car.html`의 `ART`에 적으면 바뀐다.

2026-11-14 사용자 요청으로 **탈것을 웬만한 것 다(56대)** 넣은 프롬프트로 다시 짰다(경찰차·소방차·구급차·로더·버스·택시·탱크·SUV·승용차 등).
한 장에 여덟 대씩(가로 4칸 × 세로 2줄) **시트 일곱 장** + 길가 풍경 한 장이다.

## 쓰는 법

1. ChatGPT **한 대화 안에서** ①부터 차례로 붙여 넣는다(같은 대화여야 그림체가 이어진다).
2. 새 대화에서 이어 뽑을 때는 ①로 뽑은 그림을 첨부하고 "이 그림체 그대로"라고 덧붙인다.
3. 다 뽑으면 시트를 그대로 Claude에게 준다(답이 끝난 뒤 새 메시지로). Claude가 한 대씩 잘라 넣는다.
   - 칸 순서가 곧 이름이다: **윗줄 왼쪽 → 오른쪽이 1~4, 아랫줄 왼쪽 → 오른쪽이 5~8.**
   - 한 대가 이상하게 나오면(옆으로 돌아감·두 대가 붙음) 그 탈것만 따로 한 장 뽑아도 된다 — 맨 아래 '한 대만 다시'.

## ① 출동 구조대 (이 장이 그림체를 정한다)

```
아기 그림책 스타일의 탈것 일러스트 시트. 탈것 여덟 대를 가로 4칸 × 세로 2줄로 한 칸에 한 대씩 배치한다.

[시점 — 가장 중요]
여덟 대 모두 3인칭 레이싱 게임에서 내 차를 뒤에서 따라가며 보는 시점이다.
탈것의 뒷면이 정면으로 보이고(뒤 유리, 빨간 꼬리등 두 개, 뒤 범퍼, 뒷바퀴 두 개), 카메라는 바로 뒤에서 살짝 위에 있어 지붕이 조금 보인다.
좌우 대칭이고, 화면 위쪽(앞)으로 달려가는 방향이다. 옆모습이나 비스듬한 모습은 안 된다.

[그림체]
둥글둥글한 모양, 밝은 파스텔 톤, 굵고 부드러운 진한 남색 외곽선, 단순한 면 채색에 은은한 하이라이트.
여덟 대가 모두 같은 그림체·같은 외곽선 굵기·비슷한 크기.

[배치]
칸마다 한 대만, 칸 가운데에 크게. 탈것끼리 서로 닿거나 겹치지 않게 넉넉한 간격.
얼굴(눈·입) 없음. 글자·숫자·이름표·번호판 글씨·로고 없음. 그림자·바닥·칸 테두리 없음.
투명 배경 PNG, 가로로 긴 1536×1024.

[여덟 대 — 윗줄 왼쪽부터 오른쪽으로 1~4, 아랫줄 왼쪽부터 5~8]
1. 경찰차: 흰색 차체에 파란 띠, 지붕에 빨강·파랑 경광등
2. 소방 사다리차: 빨간 큰 트럭, 지붕 위에 은색 사다리가 앞쪽으로 누워 있음, 빨간 경광등
3. 구급차: 흰색 네모난 차, 뒷문에 빨간 십자, 지붕에 빨강·파랑 경광등
4. 견인차(레커차): 노란 트럭, 뒤쪽에 갈고리 달린 크레인 팔이 솟아 있음
5. 소방 물탱크차: 빨간 트럭, 뒤에 둥근 물탱크와 감아 둔 노란 호스
6. 경찰 오토바이: 흰색·파란색 오토바이의 뒷모습(뒷바퀴 하나, 양쪽 짐가방, 뒤에 작은 경광등), 탄 사람 없음
7. 구조대 트럭: 주황색 네모난 구조 트럭, 지붕에 조명과 사다리
8. 소방 지휘차: 빨간 SUV, 지붕에 빨간 경광등
```

## ⑧ 길가 풍경 (있으면 더 예쁘다)

길 양쪽에 세워져서 멀리서 다가오는 그림이다. 탈것과 달리 **정면 모습**이다.

```
방금 시트들과 똑같은 아기 그림책 그림체(둥글둥글, 파스텔, 굵은 남색 외곽선)로 길가 풍경 시트를 그려 줘.
여덟 개를 가로 4칸 × 세로 2줄로 한 칸에 하나씩, 서로 안 닿게. 모두 정면에서 본 모습이고 아래쪽이 땅에 닿게 똑바로 서 있다.
글자·숫자·그림자·바닥·칸 테두리 없음, 투명 배경 PNG, 1536×1024.
여덟 개 — 윗줄 왼쪽부터 1~4, 아랫줄 왼쪽부터 5~8:
1. 동그란 초록 나무 한 그루
2. 세모난 소나무 한 그루
3. 빨간 세모 지붕의 작은 집(문 하나, 창문 둘, 굴뚝)
4. 창문이 많은 파스텔 색 높은 건물
5. 기둥 위에 동그란 표지판(안에 흰 별 하나, 글자 없음)
6. 신호등(빨강·노랑·초록 세 칸)
7. 줄에 묶인 풍선 세 개
8. 큰 꽃 세 송이
```

## 받은 뒤 (Claude가 하는 일)

1. 시트를 한 대씩 잘라 투명 가장자리를 다듬고 긴 쪽 640px webp로 `images/play/car/<파일 이름>.webp`에 넣는다.
2. `play/car.html`의 `ART`에 `{ police: 1, fire: 1, … }`처럼 적는다(그림을 바꾸면 숫자를 올린다).
3. **지금 게임에 없는 탈것(로더·탱크·SUV 등 39대)은 `CARS`에 이름·말풍선·경적 소리와 함께 새로 넣는다.** 지금 있는 17대는 그림만 바뀐다.
4. 로컬에서 탈것이 길 위에 바로 서는지, 길가 그림이 땅에 닿는지 확인한다.
