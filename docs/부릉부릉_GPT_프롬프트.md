# 부릉부릉 출동! — 탈것 그림 GPT 프롬프트

놀이터의 아이용 놀이 `play/car.html`(안쌤 계정 전용)에 넣을 탈것 그림을 뽑는 프롬프트다.
지금은 이모지(🚓🚒🚑…)로 보이고, 그림을 받으면 `images/play/car/<이름>.webp`로 넣은 뒤 `car.html`의 `ART`에 적으면 그림으로 바뀐다.

## 꼭 지킬 것 (모든 그림 공통)

- **옆모습, 오른쪽을 보고 달리는 방향** (앞머리가 오른쪽).
- **투명 배경**, 그림자·바닥·글자·번호판 글씨 없음.
- 한 장에 탈것 **한 대만**, 가운데에 꽉 차게(위아래 여백 조금).
- 30개월 아기가 보는 그림: 둥글둥글, 밝고 부드러운 색, 굵고 부드러운 외곽선, 웃는 얼굴은 넣지 않는다(눈·입 없는 그냥 탈것 — 타요 같은 캐릭터와 닮지 않게).
- 열두 장이 **같은 그림체**여야 한다. 첫 장이 마음에 들면 "같은 그림체로 다음"이라고 이어서 뽑는다.

## ① 그림체를 정하는 첫 장 (경찰차)

```
아기 그림책 스타일의 귀여운 경찰차 일러스트 한 대.
완전한 옆모습이고 차 앞머리가 오른쪽을 향한다.
둥글둥글한 모양, 밝고 부드러운 파스텔 톤, 굵고 부드러운 진한 남색 외곽선, 단순한 면 채색에 은은한 하이라이트.
흰색과 파란색 차체, 지붕에 빨강·파랑 경광등, 큰 바퀴 두 개.
얼굴(눈·입) 없음, 글자·숫자·로고 없음, 그림자·바닥 없음.
투명 배경 PNG, 정사각형 1024×1024, 차가 가운데에 크게.
```

## ② 같은 그림체로 한 장씩 (위 그림이 마음에 들면 이어서)

아래 줄을 하나씩 붙여 넣는다. 앞에 늘 이 문장을 붙인다:

```
방금 그림과 똑같은 그림체·외곽선·색감·크기·방향(옆모습, 앞머리가 오른쪽)으로, 투명 배경 PNG 1024×1024, 얼굴·글자·그림자 없이 한 대만:
```

| 파일 이름 | 붙일 설명 |
|---|---|
| `police` | (첫 장) 경찰차 |
| `fire` | 빨간 소방차. 지붕에 은색 사다리, 옆에 노란 호스 릴, 빨간 경광등 |
| `amb` | 흰색 구급차. 옆면에 빨간 십자 무늬, 지붕에 빨강·파랑 경광등 |
| `tow` | 노란 견인차(레커차). 뒤에 갈고리 달린 크레인 팔 |
| `car` | 빨간 작은 자동차(둥근 소형차) |
| `bus` | 노란 버스. 창문이 여러 개 줄지어 있음 |
| `taxi` | 주황색 택시. 지붕에 작은 표시등 |
| `truck` | 파란 화물 트럭. 뒤에 네모난 짐칸 |
| `excavator` | 노란 굴착기(포클레인). 긴 팔과 바가지, 무한궤도 바퀴 |
| `dump` | 주황색 덤프트럭. 뒤 짐칸이 살짝 들려 있음 |
| `mixer` | 레미콘(콘크리트 믹서 트럭). 뒤에 줄무늬 둥근 통 |
| `tractor` | 초록 트랙터. 뒷바퀴가 아주 큼 |
| `garbage` | 초록 청소차(쓰레기 수거차) |
| `train` | 빨간 증기 기관차. 굴뚝에서 하얀 연기 한 덩이 |
| `heli` | 노란 헬리콥터. 위에 큰 프로펠러, 꼬리에 작은 프로펠러 |
| `plane` | 하늘색 여객 비행기(옆모습, 수평으로 날아감) |
| `rocket` | 빨강·흰색 로켓. **옆으로 누워 오른쪽으로 날아가는 모습**, 꼬리에서 주황 불꽃 |

- 견인차·굴착기·덤프트럭·레미콘·청소차는 이모지가 없어서, **그림을 넣어야 놀이에 나온다.**
- 한 장에 여러 대를 격자(예: 4×3)로 뽑아도 된다. 그때는 "배경은 완전한 흰색 한 가지, 탈것끼리 겹치지 않게 넉넉히 띄워서"를 덧붙이면 Claude가 잘라 넣는다.

## 받은 뒤 (Claude가 하는 일)

1. 한 대씩 잘라 투명 가장자리를 다듬고 긴 쪽 640px webp로 `images/play/car/<파일 이름>.webp`에 넣는다.
2. `play/car.html`의 `ART`에 `{ police: 1, fire: 1, … }`처럼 적는다(그림을 바꾸면 숫자를 올린다).
3. 로컬에서 그 탈것이 오른쪽을 보고 길 위에 서는지 확인한다.
