# 기타 키우기 — 통기타 3세트: 크리스마스 (+0 ~ +20) 아이디어와 ChatGPT 프롬프트

2026-11-24 사용자: "크리스마스 컨셉으로 다른 악기들 프롬프트 전부 다 만들어 줘. 그리고 프롬프트 안에, zip 파일로 만들어서 기타 키우기 폴더 안에 넣어 달라고 해 줘."

스트랫 3세트(성탄 스트랫, `docs/기타키우기_GPT_스트랫3세트_크리스마스_프롬프트.md`)와 같은 규칙으로 썼다. CLAUDE.md 11절 'GPT 그림 프롬프트 쓰는 법' ①~⑤ 그대로다.
- 한 번 붙여 넣으면 A·B·C를 **쭉 다** 뽑고, 끝나면 **zip 파일 하나로 묶어 구글 드라이브 `기타 키우기` 폴더에 넣는다**(못 넣으면 내려받기 링크).
- 그림마다 헤드머신(튜닝 키)·기둥·줄 개수(양쪽 3개씩, 줄 6개)를 GPT가 스스로 세고, 틀린 기타는 **그 하나만 따로** 다시 그린다.
- 뒤·둘레에 **아우라·빛 번짐·안개·후광 빛은 넣지 않는다**. 전구·초·창·별·연기·눈보라도 외곽선이 또렷한 **단단한 모양**으로만 그린다.
- **단계 격차를 크게 + 테마는 +6부터**: +0~+4 진짜 쓰레기(크리스마스 거의 없음) → +5 수수 → **+6~+7 크리스마스 시작(싸구려 장식)** → +8~+11 '오, 멋있어지네' → +12~+19 **기타 자체가** 크리스마스 전설로 변신 → +20 그보다 더.

## 0. 이 세트의 모양과 이야기

- **세트 이름: 오두막 통기타** (게임 `dexName`, 이름은 Claude가 지음 — 바꿔도 된다).
- 1세트(방랑자 통기타)는 밝은 나무색, 2세트(동화나라 통기타)는 새까만 드레드노트라서, **3세트는 따뜻한 체리 레드 선버스트**(가장자리 진한 빨강 → 가운데 호박색)다. 마호가니 옆판, 크림 바인딩, 초록·크림 헤링본 로제트, 별갑 픽가드, 금 줄감개, 양쪽 3개씩 헤드.
- 이야기 줄기 — **포근한 겨울 오두막**
  - **+0~+4**: 춥고 먼지 쌓인 다락방과 눈 오는 현관의 쓰레기. 다락방 상자에 깔림, 난로 옆에서 바싹 말라 갈라짐, 나무좀, 착색제 통에 빠짐, 눈 오는 현관에 내놓음(+4에서 크리스마스가 살짝 비침).
  - **+5**: 닦고 고친 수수한 체리 통기타.
  - **+6~+7**: 크리스마스 시작 — 삼끈으로 묶은 솔방울, 손뜨개 스트랩과 작은 뜨개 양말. 아직 수수하다.
  - **+8~+11**: 멋있어진다. 자개 테와 전나무 상감, 북유럽 겨울 민속 무늬, 뜨개 크리스마스 스웨터, 눈 덮인 오두막 창.
  - **+12~+19**: 기타 자체가 포근한 크리스마스 장소·물건으로 변신한다. 크리스마스 랜턴, 양초 아치, 포인세티아 온실, 크리스마스 마켓 오두막, 돌아가는 나무 크리스마스 피라미드, 통나무 오두막, 등불 걸린 지붕 다리, 설산 정상의 대산장.
  - **+20**: 전설의 포크 가수가 수십 년 친 담배색 선버스트 통기타.
- 조각 마을·피라미드에는 **집·나무·순록·별만**(전통 피라미드에 흔한 천사·목동은 안 그린다).
- 스트랫 3세트의 벽난로·불탄 장작, 통기타 2세트의 동화(마법 거울·라푼젤 탑)는 피했다.
- **사람은 그리지 않는다** — 산타·요정·천사·캐럴 부르는 사람·사람 인형 모두. 산타는 그 물건(모자·옷의 흰 털·벨트·썰매·선물 자루·장화)으로만 보여 준다. 종교 그림(십자가·구유·천사)과 글자(Merry Christmas·숫자)도 넣지 않는다.
- 눈·흰 털·크림이 흰 배경에 녹아 안 보이지 않게, **흰 부분에는 또렷한 검은 외곽선과 연한 푸른 회색 그늘**을 넣게 했다.
- 크리스마스 세트끼리 안 겹치게 악기마다 다른 소재를 썼다 — 스트랫 = 산타 마을 · 텔레 = 장난감 · 레스폴 = 디저트 · 슈퍼스트랫 = 얼음과 눈 · 통기타 = 포근한 겨울 오두막 · 베이스 = 북극 동물 · 앰프 = 선물 상자 · 멀티 = 캐럴 음악 · 페달 = 트리 오너먼트.

## 2. 쓰는 법

1. ChatGPT **새 대화**에 아래 3절 프롬프트를 통째로 한 번 붙여 넣는다. 이미지 A(+0~+9), B(+10~+19), C(+20)를 **한 번에 이어서** 뽑고, 끝나면 zip까지 만든다.
2. 그림마다 헤드머신(튜닝 키)·기둥·줄 개수(양쪽 3개씩, 줄 6개)를 ChatGPT가 스스로 센다. 틀린 기타는 **그 하나만 따로** 다시 그리게 했다.
3. 중간에 멈추면 같은 대화에 `계속해 줘 — 남은 이미지를 이어서 다 그리고, 다 끝나면 zip 파일까지 만들어 줘. 매번 개수를 세고, 틀린 건 하나씩 다시 그려 줘.`를 붙여 넣는다.
4. 배경이 투명하게 안 나와도 **무늬 없는 흰 배경**이면 된다(Claude가 오려 낸다). 뿌연 안개·눈 내리는 하늘·그라데이션 배경, **뒤의 아우라·빛 번짐**만 아니면 된다.
5. **zip**: ChatGPT가 그림을 모두 PNG로 `acoustic3_christmas.zip` 하나에 묶어 구글 드라이브 **`기타 키우기`** 폴더에 넣게 했다.
   - 안의 파일 이름: `acoustic3_A.png`(+0~+9 시트) · `acoustic3_B.png`(+10~+19 시트) · `acoustic3_20.png`(+20) · 다시 그린 낱장 `acoustic3_03.png`처럼 단계 두 자리.
   - ChatGPT가 드라이브에 직접 못 넣으면 내려받기 링크를 준다 — 받아서 `기타 키우기` 폴더에 넣으면 된다.
6. 넣었다고 Claude에게 알려 주면, 풀어서 `1 악기/통기타/3세트 오두막/`에 두고 다시 세어 본 뒤 맞는 것만 잘라 넣는다.
   - 1·2세트 통기타와 같은 틀(448×672 — 헤드 위 끝 y=209, 몸통 아래 끝 y=608, 넥 가운데 x=224)에 맞추고 `images/play/gk/acoustic3_00`~`20.webp`로 넣는다.
   - 계열은 `acoustic3`. 게임에서는 통기타가 나오면 1·2·3세트가 1/3씩 나온다(넣을 때 정함 — 멀티·페달처럼 `SETS`로).
   - 서버(랭킹·오늘의 상대·최고 무기)도 'acoustic3'를 받게 SQL 한 개가 더 필요하다(기타라서 최고 무기 목록에도 넣는다).
